## 1. What Information We Process

Depending on which features you use, the Service may process:

- **Discord identifiers:** user IDs, usernames, display names, server IDs, channel IDs, role IDs
- **Reminder data:** reminder text, delivery status, timestamps, target channels/DMs
- **Moderation data:** user IDs targeted by commands, ban/timeout reasons, blacklist records
- **Campaign data:** update-preference choices (levels 0–6), DM delivery status, reaction records
- **Command input:** text, URLs, options, and parameters you provide to commands
- **Operational data:** bot health metrics, server membership counts, error logs, uptime records
- **Mention statistics:** user IDs and counts involved in mention events (not full message text)

**We do not intentionally process:**
- Full message content
- Files or media attachments
- Financial or payment information
- Biometric or health data

## 2. Why We Process Information

We process information to:

- Respond to commands and provide requested features
- Send reminders at scheduled times
- Track update-preference responses and avoid duplicate DMs
- Support server moderation and authorization
- Monitor bot health and diagnose errors
- Comply with legal obligations
- Protect security and prevent abuse

---

## 3. How We Store and Retain Information

**Runtime Files:**
- Reminder data, campaign state, and bot configuration are stored in local files on the host system
- Files persist until overwritten by new data, manually deleted, or removed by host maintenance

**Memory:**
- Some data (reminders, game state) exists in memory and is lost when the bot process stops

**Backups:**
- Host backups, logs, and provider systems may retain data beyond the bot's control

**No Automatic Deletion:**
- We do not operate an automatic scheduled deletion system
- Data remains until manually removed or overwritten by feature updates
- Deletion requests should be submitted to the Operator

**Approximate Retention:**
- Reminders: until delivery or manual deletion
- Campaign data: until next campaign cycle or manual deletion
- Moderation records: indefinitely unless deleted
- Logs and health data: subject to hosting provider retention policies
